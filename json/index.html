JSON¶

stdlib/json.kod parses and emits JSON, strictly as RFC 8259 defines it.

Quick example¶

import "json"

func main() -> int64 or Error {
    let v = try json.parse("{\"name\": \"kod\", \"tags\": [1, 2.5, \"\\u00e9\"]}")
    let name = v.get("name").as_str()
    print(name? or "?")                       // kod
    print(v.emit())                           // {"name":"kod","tags":[1,2.5,"é"]}
    print(v.emit_pretty())
    return 0
}

Parsing¶

func parse(anon src: str, max_depth: int64 = 512) -> Value or Error

Malformed input is an error you can handle, never a panic. The error is a JsonError, which carries where it went wrong:

type JsonError = struct {
    message: str     // "unexpected character", "unterminated string", ...
    offset: int64    // byte offset in the input
    line: int64      // 1-based
    column: int64    // 1-based, in bytes
}

Its to_str reads json: unexpected character at line 2, column 7. Recover it with a downcast (e is JsonError(je), see Types).

What the parser accepts is exactly JSON text: one value, with optional whitespace (space, tab, newline, carriage return) around it. It rejects, with an error saying what and where:

  • an empty input, text after the value, and a missing or doubled comma, colon or bracket;
  • trailing commas, comments, single quotes, unquoted keys, NaN, Infinity and a leading +;
  • numbers like 01, -, 1., .5, 1e and 0x10;
  • a raw control character (below U+0020) inside a string;
  • an escape other than \" \\ \/ \b \f \n \r \t \uXXXX;
  • a \u escape that isn't four hex digits, and an unpaired surrogate (\ud800 not followed by \udc00..\udfff, or a lone low surrogate);
  • nesting deeper than max_depth, which stops [[[[... from exhausting the stack. Depth counts the arrays and objects around a value, so max_depth: 1 allows [1] and not [[1]].

A UTF-8 byte order mark at the start is skipped. Bytes of 0x80 and up inside strings are taken as they are: the parser doesn't check that they are valid UTF-8.

The Value type¶

type Value = enum {
    Null
    Bool(value: bool)
    Number(value: int64)
    Str(value: str)
    Array(items: [Value])
    Object(keys: [str], values: [Value])
    Decimal(text: str)
}

An integer that fits in int64 is a Number (-0 is Number(0)). Any other number is a Decimal: one with a fraction or an exponent (2.5, 1e3, -0.0), or an integer too large for int64. A Decimal keeps the number's text exactly as it was written, so nothing is rounded and it is written back unchanged. Read it as a float64 with parse_float on as_number_text(), and build one with to_str. \uXXXX escapes are decoded into UTF-8, with a surrogate pair giving one four-byte character, and \u0000 gives a NUL byte inside the str.

Object entries are stored as parallel arrays (keys[i] is the key of values[i]), in the order they were written. A repeated key is kept, and get finds the first.

Accessors¶

Methods on Value. None of them can fail: they return Null or none when the value isn't what you asked for, so v.get("a").get("b") is safe on any input.

Method Returns
v.get(key) the first value of that key in an object; Null if the key is missing or v isn't an object
v.at(index) the element of an array; Null if out of range or v isn't an array
v.as_str() str?, for a Str
v.as_int() int64?, for a Number (a Decimal is none, even 3.0)
v.as_bool() bool?, for a Bool
v.as_array() [Value]?, for an Array
v.as_number_text() str?, the text of a Number or a Decimal
v.is_null() bool

Building values¶

Constructing a Value by hand means .Object(keys: [...], values: [...]) with two arrays that must stay in step. Two builders do the bookkeeping:

let body = json.ObjectBuilder()
body.put_str("title", "a bug")
body.put_int("priority", 2)
body.put_bool("urgent", false)
body.put("labels", json.array_of([.Str(value: "bug"), .Str(value: "ui")]))
let text = body.build().emit()
// {"title":"a bug","priority":2,"urgent":false,"labels":["bug","ui"]}
Method Meaning
put(key, value) add an entry with any Value; entries keep the order they were added in, and a repeated key is added again
put_str(key, s), put_int(key, n), put_bool(key, b), put_null(key) the same for the common cases
build() -> Value the Object; the builder can go on being used

array_of(items: Items) -> Value makes an Array from a [Value]; str_value(s), int_value(n) and bool_value(b) make the scalar Values, for building those arrays.

Emitting¶

func emit(self) -> str
func emit_pretty(self, indent: int64 = 2) -> str

Both are methods on Value: v.emit(), v.emit_pretty(indent: 4).

emit writes compact JSON with no spaces. emit_pretty puts each array element and object entry on its own line, indented by indent spaces per level, with ": " after a key; an empty array or object is [] or {}, and there is no newline at the end. Both write strings with \", \\, \b, \f, \n, \r, \t and \u00XX for any other control character, and leave everything else, UTF-8 included, as it is. The text of a Decimal is written verbatim; a Decimal built by hand whose text isn't a JSON number is written as null, so the output is always valid JSON.

Emitting what parse(s) returns gives the same JSON as s, except for the whitespace, the choice of escapes in strings, and -0 written as 0.
